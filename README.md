# SCAMGRAPH SENTINEL

AI-Powered Financial Fraud Detection & Transaction Risk Analysis

## Overview

SCAMGRAPH SENTINEL is an AI-powered financial fraud detection system designed to analyze transaction behavior and identify potentially fraudulent transactions.

The system combines feature engineering, machine learning, a Flask-based API, and an interactive web dashboard to provide transaction-level fraud risk analysis.

## Key Features

- Machine-learning-based fraud prediction
- Transaction behavior analysis
- 17 engineered transaction features
- Fraud probability and risk scoring
- Flask REST API
- Interactive web dashboard
- Health-check endpoint
- Model training and prediction pipeline
- Support for large-scale transaction datasets
